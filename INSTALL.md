## Install the gem

```
gem install comment_strip-ruby
```

or add to a **Gemfile**:

```Ruby
gem 'comment_strip-ruby'
```

then `bundle install`.


## From a source checkout

```
bundle install
bundle exec rake test
```


## Using the library

```Ruby
require 'comment_strip'
```
